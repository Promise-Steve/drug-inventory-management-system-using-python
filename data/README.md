# Data

This folder contains the simulated dataset used for the Drug Inventory Management project.

## Dataset

The project uses a simulated drug inventory dataset created specifically for demonstrating inventory analysis and decision-support processes.

The dataset contains information such as:

- Drug ID
- Drug name
- Category
- Facility
- Quantity
- Reorder level
- Maximum stock
- Unit price
- Supplier
- Expiry date

## Important Note

This is a **simulated dataset** created for educational, analytical, and portfolio purposes.

It does **not** represent real patients, hospitals, pharmacies, healthcare facilities, pharmaceutical companies, or real-world inventory records.

No personal or confidential information is contained in the dataset.
